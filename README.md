# Tutorlogy
The "Elevator Pitch": An adaptive AI mentoring platform designed to deconstruct the "hidden logic" of the OLSAT (Otis-Lennon School Ability Test). By shifting from a traditional "correct/incorrect" scoring model to a Natural Language Processing (NLP) feedback loop, the system captures and analyzes a student's cognitive process in real-time.

Technical Stack
Language: Python

Framework: Streamlit (Web UI & Deployment)

Deployment: GitHub & Streamlit Community Cloud

Research Context
This project explores how a rule-based AI engine can model human mentorship by capturing qualitative data (learner's thought process) and providing real-time, explainable feedback.

Key Research Pillars:

Explainable AI (XAI) for Mentorship: Instead of a "black box," the system uses rule-based logic to provide "Logic Calibrations" that explain why a pattern exists.

NLP Cognitive Modeling: The system uses keyword-matching to detect "Bridge Sentences," allowing it to map the learner's mental shortcuts and identify specific "logic bugs."

Operational Scalability: Designed as a Streamlit web application, the system demonstrates how complex educational psychological scaffolding can be deployed via a lightweight, scalable software architecture.

The Human Impact: The project aims to reduce academic pressure by fostering self-efficacy. It teaches students that logic is a masterable "system" rather than an innate talent—embodying the principle of Plus Ultra: going beyond perceived limits through belief and structured reasoning.
